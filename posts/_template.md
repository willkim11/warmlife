# 블로그 글 작성 템플릿 — 따뜻한 일상

이 파일은 Claude에게 블로그 글 작성을 지시할 때 참고하는 템플릿입니다.
새 글을 작성할 때는 아래 형식을 따라 `posts/` 폴더에 `.mdx` 파일로 저장해 주세요.

---

## 파일 규칙

- **파일명**: 영문 소문자, 하이픈(-) 사용. 예: `iphone-16-review.mdx`
- **위치**: `posts/` 폴더
- **형식**: `.mdx` (Markdown + JSX)

---

## Frontmatter 필수 항목

```
---
title: "글 제목 (40자 이내 권장, 검색 키워드 포함)"
date: "YYYY-MM-DD"
description: "글 요약 (80-100자. 검색 결과에 표시되는 문장)"
category: "카테고리"
published: true
---
```

### 카테고리 목록

- `IT/테크` — 앱, 기기, 소프트웨어 리뷰
- `생활정보` — 일상 팁, 유용한 정보
- `경제/재테크` — 금융, 투자, 절약
- `리뷰` — 제품, 서비스, 장소 리뷰
- `블로그` — 블로그 운영 관련

---

## 본문 구조 (SEO 최적화)

```markdown
---
(frontmatter)
---

첫 문단: 핵심 내용 요약 + 독자가 얻는 것 (3-4줄)

## 소제목 1 (H2)

본문 내용. 단락은 3-4줄 이내로 짧게.

## 소제목 2 (H2)

본문 내용.

### 세부 항목 (H3, 필요 시)

내용.

## 마무리

핵심 내용 1-2줄 요약. 독자에게 다음 행동 유도.
```

## 작성 가이드라인

### 분량
- 최소 800단어 이상 (AdSense 승인 + SEO 기준)
- 권장 1,200~1,500단어

### 문체
- 구어체, 친근한 어투 ("~해요", "~입니다" 혼용 가능)
- 어려운 용어는 쉽게 풀어서 설명
- 개인 경험이나 의견 반드시 포함 (AI 복제 방지, E-E-A-T)

### SEO
- 제목(H1)에 핵심 키워드 포함
- H2 소제목에도 관련 키워드 자연스럽게 포함
- 첫 문단 안에 핵심 키워드 1회 이상 등장
- 내부 링크: 관련 글이 있으면 본문에서 링크 연결

### 피해야 할 것
- AI가 쓴 것 같은 딱딱하고 나열식 문장
- "첫째, 둘째, 셋째" 형식의 기계적인 구조
- 개인 경험 없이 인터넷 정보만 재조합한 글

## Claude에게 글 요청하는 방법

아래 형식으로 요청하면 이 블로그에 맞는 글을 작성합니다:

```
다음 조건으로 블로그 글을 작성해줘:

- 주제: [글 주제]
- 키워드: [타겟 검색 키워드]
- 카테고리: [카테고리명]
- 분량: 1,000단어 이상
- 파일명: [영문-파일명.mdx]

posts/_template.md 의 형식을 따라서 작성해줘.
```
