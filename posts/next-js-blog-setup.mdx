Next.js로 개인 블로그를 만들면서 겪은 일들을 정리합니다.

튜토리얼대로 했는데 안 되는 경우가 많아서, 실제로 부딪힌 문제들 위주로 씁니다.

## 시작 — create-next-app

```bash
npx create-next-app@latest my-blog --typescript --tailwind --app
```

App Router, TypeScript, Tailwind를 한 번에 설정해줍니다. 2026년 기준으로는 이게 표준이에요.

## MDX 설정

글을 Markdown으로 쓰고 싶어서 `@next/mdx`를 사용했습니다.

```bash
npm install @next/mdx @mdx-js/loader @mdx-js/react next-mdx-remote
```

`next.config.ts`에 설정을 추가하면 `.mdx` 파일을 페이지처럼 사용할 수 있어요.

## 폰트 설정 — Pretendard

한국어 블로그라면 Pretendard 폰트를 강력 추천합니다.

Google Fonts를 쓰면 외부 요청이 생겨서 속도에 영향을 줍니다. self-hosting이 훨씬 낫습니다.

```css
@font-face {
  font-family: "Pretendard";
  src: url("/fonts/Pretendard-Regular.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;
}
```

`font-display: swap`을 꼭 넣어야 폰트 로딩 중에도 텍스트가 보입니다.
