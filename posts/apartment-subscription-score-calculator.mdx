청약을 한 번이라도 알아봤다면 "가점이 얼마나 돼야 당첨이 되나요?"라는 질문을 꼭 하게 되죠. 같은 단지 같은 평형이라도 가점 커트라인이 50점대에서 70점대까지 달라지거든요.

내 가점이 몇 점인지 아는 게 먼저예요. 생각보다 계산이 복잡하지 않으니까, 이 글 보면서 직접 계산해보세요.

## 청약 가점 구성 — 3가지 항목

청약 가점은 아래 세 가지 항목의 합산이에요.

| 항목 | 최대 점수 |
|-----|---------|
| 무주택 기간 | 32점 |
| 부양가족 수 | 35점 |
| 청약통장 가입 기간 | 17점 |
| **합계** | **84점** |

## 항목 1 — 무주택 기간 (최대 32점)

무주택 기간은 세대주 본인과 배우자의 무주택 기간을 기준으로 해요.

| 1년 미만 | 2점 |

| 2년 이상 ~ 3년 미만 | 6점 |
| 3년 이상 ~ 4년 미만 | 8점 |
| 4년 이상 ~ 5년 미만 | 10점 |
| 5년 이상 ~ 6년 미만 | 12점 |
| 6년 이상 ~ 7년 미만 | 14점 |
| 7년 이상 ~ 8년 미만 | 16점 |
| 8년 이상 ~ 9년 미만 | 18점 |
| 9년 이상 ~ 10년 미만 | 20점 |
| 10년 이상 ~ 11년 미만 | 22점 |
| 11년 이상 ~ 12년 미만 | 24점 |
| 12년 이상 ~ 13년 미만 | 26점 |
| 13년 이상 ~ 14년 미만 | 28점 |
| 14년 이상 ~ 15년 미만 | 30점 |
| 15년 이상 | 32점 |

**주의**: 만 30세 이전에 세대주인 경우, 30세가 된 날부터 무주택 기간 산정이 시작돼요. 과거에 집을 소유한 이력이 있다면, 처분한 날부터 다시 기간을 셉니다.

## 항목 2 — 부양가족 수 (최대 35점)

부양가족 수는 청약 통장 명의자(세대주) 기준으로, 함께 거주하는 가족 수를 세어요.

| 부양가족 수 | 점수 |
|----------|-----|
| 0명 | 5점 |
| 1명 | 10점 |
| 2명 | 15점 |
| 3명 | 20점 |
| 4명 | 25점 |
| 5명 | 30점 |
| 6명 이상 | 35점 |

**포함 기준:**
- 배우자 (주민등록 분리돼 있어도 포함)
- 직계존속 (부모, 조부모) — 청약 신청자 또는 배우자와 동일 주민등록에 등재되어 있어야 하고, 3년 이상 함께 거주 조건
- 직계비속 (자녀, 손자녀) — 미혼이고 만 30세 미만

**가장 많이 헷갈리는 부분**: 부모님을 모시고 있어도 주민등록상 분리돼 있으면 부양가족으로 인정이 안 될 수 있어요. 3년 이상 동일 주소에 등록돼 있어야 해요.

청약저축, 청약예금, 청약부금, 주택청약종합저축 중 하나의 가입 기간이에요.

## 내 가점 계산 예시

30대 초반 1인 가구, 무주택 5년, 청약통장 7년이라면:

- 무주택 기간 5년 = 12점
- 부양가족 0명 = 5점
- 청약통장 7년 = 9점
- **합계 = 26점**

서울 인기 단지에서 26점은 쉽지 않지만, 입지가 다소 떨어지는 단지나 추첨제 물량을 노리면 가능성이 있어요.

## 가점이 낮다면?

가점이 낮은 분들은 **추첨제** 물량을 노리는 게 현실적인 전략이에요. 공공분양이나 민영 중에서 추첨 비율이 높은 단지를 찾아보세요.

또는 아직 시간이 있다면 통장을 유지하면서 무주택 기간을 쌓는 게 가장 확실한 방법이에요.
