민영주택 청약에서 가점제가 적용되면 당첨 가능성은 무주택기간, 부양가족 수, 청약통장 가입기간으로 결정됩니다. 총점은 **84점 만점**입니다.

청약 가점은 대략으로 계산하면 안 됩니다. 세대주 여부, 배우자 분리세대, 부모님 동거 기간, 만 30세 전 혼인 여부처럼 세부 기준에 따라 점수가 달라질 수 있습니다.

## 청약 가점 84점 구성

| 항목 | 최고점 |
| --- | --- |
| 무주택기간 | 32점 |
| 부양가족 수 | 35점 |
| 청약통장 가입기간 | 17점 |
| 합계 | 84점 |

청약홈에서 제공하는 청약가점 계산기를 쓰면 가장 안전합니다. 다만 계산 원리를 알아두면 공고문을 읽을 때 훨씬 덜 헷갈립니다.

## 무주택기간 점수

무주택기간은 최대 32점입니다. 기간이 길수록 점수가 올라갑니다.

| 무주택기간 | 점수 |
| --- | --- |
| 1년 미만 | 2점 |
| 1년 이상~2년 미만 | 4점 |
| 2년 이상~3년 미만 | 6점 |
| 3년 이상~4년 미만 | 8점 |
| 4년 이상~5년 미만 | 10점 |
| 5년 이상~6년 미만 | 12점 |
| 6년 이상~7년 미만 | 14점 |
| 7년 이상~8년 미만 | 16점 |
| 8년 이상~9년 미만 | 18점 |
| 9년 이상~10년 미만 | 20점 |
| 10년 이상~11년 미만 | 22점 |
| 11년 이상~12년 미만 | 24점 |
| 12년 이상~13년 미만 | 26점 |
| 13년 이상~14년 미만 | 28점 |
| 14년 이상~15년 미만 | 30점 |
| 15년 이상 | 32점 |

무주택기간은 일반적으로 만 30세가 되는 날부터 계산합니다. 다만 만 30세 전에 혼인했다면 혼인신고일부터 계산할 수 있습니다.

과거 주택을 소유한 적이 있으면, 주택을 처분해 무주택자가 된 날부터 다시 계산해야 합니다.

## 부양가족 점수

부양가족 수는 최대 35점입니다. 기본 0명은 5점이고, 1명 늘 때마다 5점씩 올라갑니다.

| 부양가족 수 | 점수 |
| --- | --- |
| 0명 | 5점 |
| 1명 | 10점 |
| 2명 | 15점 |
| 3명 | 20점 |
| 4명 | 25점 |
| 5명 | 30점 |
| 6명 이상 | 35점 |

배우자는 주민등록표상 분리되어 있어도 부양가족으로 봅니다. 부모님 같은 직계존속은 청약신청자 또는 배우자와 같은 주민등록표에 3년 이상 계속 등재되어 있어야 인정됩니다.

자녀 등 직계비속은 미혼 자녀가 기본이고, 만 30세 이상 미혼 자녀는 최근 1년 이상 같은 주민등록표에 등재되어 있어야 하는 등 세부 기준을 확인해야 합니다.

## 청약통장 가입기간 점수

청약통장 가입기간은 최대 17점입니다.

| 가입기간 | 점수 |
| --- | --- |
| 6개월 미만 | 1점 |
| 6개월 이상~1년 미만 | 2점 |
| 1년 이상~2년 미만 | 3점 |
| 2년 이상~3년 미만 | 4점 |
| 이후 1년마다 | 1점씩 증가 |
| 15년 이상 | 17점 |

청약통장을 오래 유지할수록 유리합니다. 오래전에 만든 통장이 있다면 해지하지 말고 유지 여부를 먼저 확인하는 것이 좋습니다.

## 계산 예시

30대 후반 무주택 세대주가 무주택기간 6년, 부양가족 2명, 청약통장 가입기간 8년이라면 다음처럼 계산할 수 있습니다.

| 항목 | 점수 |
| --- | --- |
| 무주택기간 6년 이상~7년 미만 | 14점 |
| 부양가족 2명 | 15점 |
| 청약통장 가입기간 8년 이상~9년 미만 | 10점 |
| 합계 | 39점 |

39점이 높은지 낮은지는 지역, 주택형, 공급물량, 특별공급 여부, 경쟁률에 따라 달라집니다. 서울 인기 단지는 훨씬 높은 점수가 필요할 수 있고, 추첨제 물량이 있는 단지는 가점이 낮아도 기회가 있을 수 있습니다.

## 신청 전 체크리스트

- 청약하려는 주택이 가점제인지 추첨제인지 확인합니다.
- 무주택기간 시작일을 정확히 확인합니다.
- 부모님을 부양가족으로 넣을 수 있는지 주민등록 등재 기간을 확인합니다.
- 만 30세 이상 미혼 자녀의 등재 기간을 확인합니다.
- 청약통장 가입일과 납입 인정 여부를 확인합니다.
- 청약홈 계산기로 최종 점수를 다시 확인합니다.
