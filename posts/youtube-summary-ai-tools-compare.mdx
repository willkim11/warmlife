1시간짜리 유튜브 강의, 처음부터 끝까지 보기 부담스러울 때 있잖아요. 저도 공부할 때 영상 요약 툴을 즐겨 쓰는데, 어떤 툴이 가장 나에게 맞는지 계속 찾게 되더라고요. 실제로 써보고 가장 실용적인 5가지를 비교해봤어요.

## 1. YouTube Summary with ChatGPT (크롬 확장 프로그램)

**무료 여부**: 확장 프로그램 자체는 무료. (본인의 ChatGPT 계정 연동)

유튜브 영상 페이지 우측에 자동으로 요약 박스가 생겨요. 자막이 있는 영상이라면 텍스트로 스크립트를 추출하고, 클릭 한 번에 그걸 ChatGPT로 넘겨서 요약해주는 방식이에요.

**장점**: 한 번 설치해두면 유튜브 화면 안에서 바로 쓸 수 있어 접근성이 최고예요.
**단점**: 영상 자체에 자막(CC)이 없으면 동작하지 않아요. 

크롬 웹스토어에서 "YouTube Summary with ChatGPT"로 검색하면 쉽게 설치할 수 있어요.

## 2. Lilys AI (릴리스) — 한국어 요약의 끝판왕

**무료 여부**: 무료 사용 가능 (월 요약 횟수 및 영상 길이 제한 있음)

클로바노트 같은 음성 인식 앱에 유튜브 영상을 다운받아 올리는 건 불법이고 너무 번거롭죠. 릴리스 AI는 국내에서 만든 유튜브 요약 특화 툴입니다. 사이트에 유튜브 URL만 붙여넣으면 끝나요.

**장점**: 한국어 요약 퀄리티가 압도적이에요. 시간대별 타임스탬프 요약은 물론이고, 영상 내용을 바탕으로 블로그 글 초안까지 깔끔하게 뽑아줍니다.
**단점**: 1시간이 넘어가는 너무 긴 영상은 요약에 시간이 다소 걸리고, 무료 버전에서는 횟수 제한이 빡빡할 수 있어요.

한국어 유튜브 강의나 정보성 영상을 깔끔한 노트 형태로 정리하고 싶을 때 1순위로 추천해요.

## 3. Gemini (구글)

**무료 여부**: 구글 계정만 있으면 무료 (Gemini Flash/Pro)

구글 Gemini는 유튜브와 같은 집안 식구라 연동이 정말 자연스러워요. 대화창에 유튜브 링크를 붙여넣거나 "@YouTube"를 태그하고 "이 영상 핵심만 요약해줘"라고 하면 바로 처리해 줍니다. 

**장점**: 구글 공식 서비스라 외부 툴을 거치지 않아도 되고 속도가 매우 빠릅니다. 자막이 없는 영상도 자체적으로 화면과 소리를 분석해 요약해 내는 능력이 탁월해요.
**단점**: 가끔 영상의 세부적인 디테일을 놓치고 너무 크게만 요약할 때가 있어요.

유튜브 영상을 보다가 "이거 내용이 뭐지?" 싶을 때 가장 빠르고 가볍게 툭 던져보기 좋아요.

## 4. Summarize.tech

**무료 여부**: 매일 일정 횟수 무료.

해외 툴인데, URL만 붙여넣으면 긴 영상의 요약을 순식간에 생성해줘요. 별도 회원가입 없이 바로 쓸 수 있어서 진입 장벽이 가장 낮습니다.

**장점**: 가입 불필요, 2~3시간짜리 엄청나게 긴 영상도 빠르게 처리해요.
**단점**: 기본적으로 영어를 기반으로 동작해서, 한국어 영상을 넣어도 영어로 요약해 주는 경우가 많아요. 

해외 테크 유튜버의 리뷰 영상이나 외국어 컨퍼런스 영상 내용을 번역 요약본으로 빠르게 훑어볼 때 유용해요.

## 5. ChatGPT (URL 직접 입력 또는 수동 복사)

**무료 여부**: 무료 버전(GPT-4o 등) 사용 가능.

요즘 ChatGPT는 브라우징 기능이 좋아져서, 프롬프트 창에 **유튜브 URL을 그대로 붙여넣고 "요약해 줘"라고 하면 알아서 웹을 읽고 요약**해 줍니다. 

**💡 만약 URL을 읽지 못하는 에러가 난다면? (플랜 B)**
영상 페이지 → 점 세 개 메뉴 → 대본(스크립트) 표시 → 텍스트 전체 복사 → ChatGPT에 붙여넣기

**장점**: 요약 방식, 글의 길이, 말투 등을 내가 원하는 대로 아주 세밀하게 지시(프롬프팅)할 수 있어요.
**단점**: 스크립트를 수동으로 긁어와야 할 때는 모바일에서 하기가 좀 번거롭습니다.

## 결론: 상황에 따라 골라 쓰기

| 상황 | 추천 툴 |
|-----|--------|
| 한국어 강의를 완벽한 노트로 정리 | **Lilys AI (릴리스)** |
| 구글 생태계에서 가장 빠르고 간편하게 | **Gemini** |
| 크롬으로 PC 유튜브를 자주 볼 때 | **YouTube Summary 확장** |
| 회원가입 없이 해외 긴 영상 훑어보기 | **Summarize.tech** |
| 내 입맛대로 요약본 형식을 바꾸고 싶을 때 | **ChatGPT** |

완벽한 AI 툴 하나만 고집하기보다는, 영상의 언어나 내가 원하는 결과물(단순 요약 vs 노트 필기)에 따라 2~3가지를 즐겨찾기 해두고 골라 쓰는 게 가장 똑똑한 방법이에요.
