1시간짜리 유튜브 강의, 처음부터 끝까지 보기 부담스러울 때 있잖아요. 저도 공부할 때 영상 요약 툴을 즐겨 쓰는데, 쓸 만한 게 어딘지 계속 찾게 돼요. 실제로 써보고 비교해봤어요.

## 1. YouTube Summary with ChatGPT (크롬 확장 프로그램)

**무료 여부**: 크롬 확장 프로그램 자체는 무료. ChatGPT 계정 필요.

유튜브 영상 페이지에 자동으로 요약 버튼이 생겨요. 자막이 있는 영상이라면 텍스트로 스크립트를 추출하고, 그걸 ChatGPT에 넘겨서 요약해주는 방식이에요.

**장점**: 설치만 하면 바로 써요. 추가 비용 없음.
**단점**: ChatGPT 연동이라 자막이 없는 영상은 동작하지 않아요. 한국어 자막이 있는 영상에선 한국어로 요약이 잘 돼요.

크롬 웹스토어에서 "YouTube Summary with ChatGPT"로 검색하면 돼요.

## 2. Summarize.tech

**무료 여부**: 월 일정 횟수 무료, 그 이상은 유료.

URL만 붙여넣으면 영상 요약을 영어로 생성해줘요. 별도 가입 없이 바로 쓸 수 있어서 진입 장벽이 낮아요.

**장점**: 가입 불필요, 빠름.
**단점**: 요약이 영어로만 나와요. 한국어 영상도 영어 요약이에요. 한 달에 쓸 수 있는 횟수 제한이 있어요.

간단하게 해외 유튜브 영상 내용이 뭔지 빠르게 파악할 때 유용해요.

## 3. Gemini (구글)

**무료 여부**: 무료 플랜에서 가능.

구글 Gemini는 유튜브와 연동이 자연스러워요. 유튜브 링크를 붙여넣고 "이 영상 요약해줘"라고 하면 바로 해줘요. 공식 유튜브 연동이다 보니 자막 없는 영상도 처리하는 경우가 있어요.

**장점**: 구글 서비스라 유튜브 연동이 가장 자연스러워요. 한국어도 잘 돼요.
**단점**: 모든 영상이 되는 건 아니에요. 길이가 너무 길거나 자막이 완전히 없는 경우 실패할 때가 있어요.

일단 Gemini에 먼저 시도해보는 걸 추천해요.

## 4. Clova Note (네이버)

**무료 여부**: 월 300분 무료.

유튜브 URL을 직접 넣는 기능보다는, 영상 파일이나 음성 파일을 업로드해서 텍스트로 변환하는 데 강해요. 유튜브 영상을 저장해서 업로드하거나, 음성을 녹음해서 올리면 정확도 높은 한국어 받아쓰기가 돼요.

**장점**: 한국어 정확도가 가장 높아요. 발화자 구분도 해줘요.
**단점**: 유튜브 URL 직접 입력은 안 되고, 파일을 거쳐야 해요. 한 단계 더 필요해요.

강의나 인터뷰처럼 음성이 중요한 콘텐츠를 텍스트로 남기고 싶을 때 최고예요.

## 5. ChatGPT (직접 요청)

**무료 여부**: 무료 버전 사용 가능.

ChatGPT에 유튜브 URL을 직접 넣으면 안 되지만, 영상의 자막이나 스크립트 텍스트를 복사해서 붙여넣고 "이걸 요약해줘"라고 하면 돼요. 유튜브 영상 페이지에서 자막을 텍스트로 꺼내는 방법은 간단해요.

영상 페이지 → 점 세 개 메뉴 → 대본 열기 → 텍스트 전체 복사 → ChatGPT에 붙여넣기

**장점**: 요약 방식, 길이, 형식을 내가 원하는 대로 지시할 수 있어요.
**단점**: 수동으로 스크립트를 꺼내야 해서 번거로워요.

## 결론: 상황에 따라 골라 쓰기

| 상황 | 추천 툴 |
|-----|--------|
| 빠르게 해외 영상 파악 | Summarize.tech |
| 구글 생태계 쓰는 중 | Gemini |
| 한국어 영상 정확하게 텍스트로 | Clova Note |
| 크롬 사용, ChatGPT 계정 있음 | YouTube Summary 확장 |
| 요약 방식 직접 제어하고 싶음 | ChatGPT + 수동 스크립트 |

완벽한 툴 하나는 없어요. 영상 언어, 자막 유무, 원하는 요약 형식에 따라 맞는 걸 골라 쓰는 게 현실적이에요.
